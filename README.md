## Featured build: Pocket Arcade

### [Pocket Arcade — live demo](https://arcade-game-five.vercel.app/)  
**Five original browser arcade games in one responsive web app — procedural graphics, synthesized audio, local + global leaderboards, and a serious test suite.**

[![Live Demo](https://img.shields.io/badge/Play-Live_Demo-4DFFE1?style=for-the-badge)](https://arcade-game-five.vercel.app/)
[![Repo](https://img.shields.io/badge/Code-Repository-181717?style=for-the-badge&logo=github)](https://github.com/harshvardhan579/arcade-game)
![TypeScript](https://img.shields.io/badge/TypeScript-strict-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Phaser](https://img.shields.io/badge/Phaser-3.90-8A4FFF?style=for-the-badge)
![Vercel](https://img.shields.io/badge/Deploy-Vercel-000?style=for-the-badge&logo=vercel)

**Why it matters:** Pocket Arcade is not just a game demo. It's a shipped frontend/full-stack engineering project with deterministic game logic, a Vercel/Supabase global leaderboard, mobile controls, dark/light themes, and automated validation across unit, browser, API, and visual-regression-style tests.

**What I built:**

- **5 games:** Neon Serpent, Bounce Circuit, Star Courier, Lane Rush, Circuit Stack.
- **Zero runtime assets:** no images, sprites, fonts, or audio files; visuals are procedural and audio is synthesized with WebAudio.
- **Architecture boundary:** pure deterministic `*Logic.ts` engines separated from Phaser renderers, enforced by a custom import-boundary check.
- **Global leaderboard:** Vercel serverless API + Supabase Postgres, server-side name validation, profanity/reserved-name filtering, score plausibility checks, salted-IP rate limiting, and server-only service-role key.
- **Testing discipline:** Vitest logic tests, Playwright desktop/mobile e2e, pixel-signature canvas regression tests, mobile no-scroll layout checks, API typecheck, lint, Prettier, and secret-grep safety checks.
- **Product polish:** home screen, procedural game emblems, local highs, global scores, responsive mobile controls, dark/light themes, reduced-motion support.

**Tech:** TypeScript, Vite, Phaser 3, Playwright, Vitest, Vercel Functions, Supabase Postgres, WebAudio, CSS custom properties.
